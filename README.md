# Alke Wallet 📱💼

¡Bienvenido al repositorio de **Alke Wallet**! Este proyecto consiste en el desarrollo del Front-end dinámico para una billetera digital.

Este trabajo fue desarrollado de forma progresiva a lo largo del **Módulo 2: Fundamentos del desarrollo Front-end** .

---

## 🎯 Objetivo del Proyecto

El propósito principal es entregar una interfaz completamente funcional, responsiva y semántica que permita simular las operaciones de aplicación wallet: autenticación, revisión de saldos, transferencias y registro de movimientos.

---

## 🚀 Funcionalidades Principales (Requerimientos)

* **Inicio de Sesión:** Acceso mediante formularios inicio de sección para cuentas de usuario (`login.html`).
* **Administración de Fondos:** Visualización del saldo disponible, con flujos interactivos para realizar depósitos (`deposit.html`, `menu.html`).
* **Envío y Recepción de Dinero:** Simulación de transferencia de fondos a contactos agendados y recepción de activos (`sendmoney.html`).
* **Historial de Transacciones:** Registro estructurado y legible de todos los movimientos simulados dentro de la plataforma (`transactions.html`).

---

## 🛠️ Tecnologías y Herramientas Utilizadas

Para el desarrollo de la interfaz de usuario se implementó el siguiente stack:

* **HTML5:** Estructuración semántica del contenido para garantizar accesibilidad.
* **CSS3:** Estilos personalizados.
* **Bootstrap 5:** Framework CSS utilizado para el diseño responsivo, grillas y componentes.
* **JavaScript (ES6):** Lógica dinámica para la validación de credenciales, gestión de eventos de botones y operaciones financieras básicas.
* **jQuery:** Manipulación eficiente del DOM, animaciones de transición en el menú y funcionalidad de autocompletar en la búsqueda de contactos.
* **Git & GitHub:** Control de versiones bajo una estrategia de ramificación estructurada.
